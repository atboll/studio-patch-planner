# Studio Patch Planner

A web tool for planning patchbays and XLR panels in recording studios. Answer a short interview (rooms and XLR panels, house rules, preamps, converters, outboard, monitoring) and it lays out the patchbays, with normalling, checks and XLR panel drawings.

**Try it:** https://atboll.github.io/studio-patch-planner/

- Bantam (TT) 2 × 48 or jack 2 × 24 bays
- Drag labels to move units, double-click a name to rename it
- Normalling per point: click the number between the jacks
- Export the bay overview as PDF, the points as an Excel workbook, or save the project as a file
- Press **Demo** to load an example studio

Everything runs in the browser in one file (`index.html`). Nothing is sent to a server; work in progress is kept in the browser's local storage.
